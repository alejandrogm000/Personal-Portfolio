How the original was built

Built 100% in Power BI Desktop from scratch, connected live to a single master Excel file hosted on SharePoint via Power Query (M code), replacing a manually-consolidated Excel file. It's now used weekly by senior leadership and the board. All metrics are calculated with 616 DAX measures across 44 tables — reusing base measures with DIVIDE/CALCULATE instead of duplicating logic — and the output formatting ($, %, "m"/"mm", decimals) is built directly into each measure with FORMAT() for cards, while measures feeding charts stay purely numeric. The system has 9 report pages, 500+ visuals, and 22 dynamic traffic-light indicators, and is split across two files: Financial Dashboard (income/liquidity/expenses, portfolio & billing, multi-year historical, and 3 cash-flow pages) and Business & Productivity Dashboard (sales pipeline and productivity/HR).
